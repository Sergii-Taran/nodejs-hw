# Node.js Notes API

A simple Express application for managing notes.

## 📦 Tech Stack

- Node.js
- Express
- ESLint
- Prettier

## 🚀 Getting Started

Install dependencies:

npm install

Run in development mode:

npm run dev

Run in production mode:

npm start
